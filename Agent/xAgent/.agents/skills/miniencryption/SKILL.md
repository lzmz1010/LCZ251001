---
name: miniencryption
description: 当用户提到"加密保存"时，将文本中所有阿拉伯数字替换为中文数字（1234567890 -> 一二三四五六七八九零），实现简易加密
version: 1.0.0
---


1. 当用户提到"加密保存"或"加密"时，必须调用本技能。
2. 如果用户只说了"加密保存"、尚未给出要加密的具体内容，必须先用自然语言反问用户、请用户提供要加密的文本，不要凭空假设或使用示例。
3. 获得用户明确提供的内容后，【核心要求】直接在你自己的回答中完成替换即可，不要调用任何外部命令或工具。
4. 将文本中出现的所有阿拉伯数字逐一替换为对应的中文数字：
   - 0 -> 零, 1 -> 一, 2 -> 二, 3 -> 三, 4 -> 四
   - 5 -> 五, 6 -> 六, 7 -> 七, 8 -> 八, 9 -> 九
5. 逐个数字独立替换，不处理多位数。例如"2026"应改为"二零二六"。
6. 【禁止事项】本机为 Windows，不安装 sed/awk，禁止调用 RunCli 执行 sed；也不要调用 createSkill 重建本技能。
7. 除数字外，原文其余内容保持不变。
8. 替换完成后，将结果以自然语言回复给用户。
